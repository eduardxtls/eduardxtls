## 💻 My Featured Projects

### 🎓 Master's Thesis
> **Gaze Sharing AR Application**
* **Technologies:** C# and Unity (Android-based Meta Quest App), Python (Data Processing, Backend)
* **Focus Areas and Concepts:** Augmented Reality, Eye Tracking, Gaze Analytics, Object Recognition, Human-Computer Interaction, Accessible Design, UDP/TCP Networking
* **Overview:** My Master's Thesis revolved around the effects of gaze sharing on individuals with visual impairment and how this new information channel extends their perception. I developed an Android-based application running on the Meta Quest 3S that highlights the currently focused object by a sighted person. Eye tracking data was collected using the Pupil Labs Neon and a Python backend processes the data, running object recognition on the scene and determining the gaze focus of the sighted person.
* 🔗 Find out more: [Repository / Code ](https://github.com/eduardxtls/ARGazeSharing)

### 🎓 Bachelor's Thesis
> **Eye Contact AR Application**
* **Technologies:** C#, Unity
* **Focus Areas and Concepts:** Augmented Reality, Spatial Anchors and Tracking, Audio-Visual Feedback, Accessible Design, UDP Networking
* **Overview:** This application was implemented during my Bachelor's Thesis and it helps individuals with visual impairment locate a companion more easily. It was made for the HoloLens 2 AR device using Unity and C#. Communication is implemented via UDP and QR codes are used to locate each device in relation to spatial anchors. Device positions are communicated between both users over a C# server and visual highlights are provided to the individual with visual impairment.
* 🔗 Find out more: [Repository / Code](https://github.com/eduardxtls/EyeContactAR)
